Minecraft Server Integration

Bridge your in-game chat, server logs, death notifications, whitelisting, and more to your Discord server.

1

Add the Bot

Invite the After Hours bot to your Discord server. The bot is free, out of alpha, and doesn't require any administrator privileges (it only needs permissions to read and send messages, manage webhooks, and register commands).

Invite Bot
2

Generate Connection Token

Run the /mc connect command inside your Discord guild. This command tests RCON connectivity, sets up your guild's routing table, and generates a secure, one-time server token to bind the bridge.

Discord Command
/mc connect <rcon_host> <rcon_port> <rcon_password> <chat_channel> [log_channel]
3

Install the Paper/Java Plugin

Download our lightweight Paper plugin, drop it into your server's plugins/ directory, and paste your generated token in the configuration file.

📥 Download JugaadBridge.jar

Once you start your Minecraft server, open plugins/JugaadBridge/config.yml and paste your token and API URL:

api-url: 'https://jugaadapi.arshnah.in/mc-event' token: 'your_generated_token_here'

Save the file and run /jugaad reload (or restart the server) to activate the bridge.
